# NursingHomeGrade wordmark — v3

This is an iteration of the existing outlined Noto Serif Display wordmark. It preserves the source glyph paths and their existing kerning; it is not a custom-drawn typeface.

## Changes from v2
- Highlight x=6868, y=-45, width=3180, height=970, radius=42 SVG units.
- Highlight left/right and vertical whitespace enlarged; visual corners softened.
- Added transparent monochrome and reversed variants.
- Added stacked variant using the same paths for narrow layouts.
- Kept Grade spacing and letterforms from v2; no unverified claims of custom kerning.

## Verification
All four SVG files parsed and rendered to 1800px PNG with CairoSVG. A proof sheet shows large, 320px, 240px and stacked uses. The 240px horizontal lockup is still a legibility limit; use stacked or text in compact headers.

## Design review
Aesthetic score 9.1/10 is an internal subjective target assessment, NOT an independent or blind reviewer score. A genuine independent assessment has not occurred. Remaining opportunity: custom glyph refinement and in-browser tests against real navigation.

Do not use an A rating seal as the company icon, since it can be confused with a facility rating.
